# سامان ویندوز – خلاصه وضعیت (هندآف)
مالک و برنامه‌نویس: مجید رستگارمقدم – دیجی سرویس

## فناوری
C# + WPF روی .NET Framework 4.8 (x64)، SQLite (حالت Lite)، Dapper، QRCoder. سه پروژه: Saman.Core، Saman.Data، Saman.UI. بیلد با GitHub Actions.

## انجام‌شده (کامپایل‌نشده و تست‌نشده)
- میز کار ۵ ستونه با درگ‌اندراپ
- پذیرش هوشمند متنی فارسی (آفلاین)
- رسید A5 / حرارتی ۸۰mm / هر دو با QR
- سابقه تعمیر و گارانتی بر اساس سریال و تاریخ تحویل
- تنظیمات: تب «رسید و چاپ»
- شماره پذیرش از ۱۳۰۱

## منتظر تأیید
- طرح شناسنامه دستگاه + نقشه برد (فایل HTML نمایشی)

## فهرست کارهای باقی‌مانده
1. گزارش عملکرد (Audit log) با کد کاربر و ساعت
2. معماری ماژولار + لایسنس بسته‌ها
3. عکس دستگاه در پذیرش (فایل روی دیسک، فشرده)
4. بانک تجربیات فنی بر اساس مدل (بدون داده مشتری)
5. انتقال و همگام‌سازی با نسخه اندروید (ابتدا فایلی، سپس Sync)
6. خدمات در محل مشتری
7. نصب‌کننده خودکار (Inno Setup)
8. نسخه شبکه (SQL Server Express)
9. پشتیبانی آنلاین و AnyKey (نام برنامه مشخص شود)
10. صفحه درباره ما با امضای مالک
11. پورسانت و امتیاز پرسنل
12. تب‌های باقی‌مانده تنظیمات، مشتریان، انبار، مالی، بکاپ، لایسنس
